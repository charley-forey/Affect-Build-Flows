You are here: [Glossary](Glossary.md) > Custom Reports (shared) folder

If you create a custom report in **13-3 Report Writer**, it is saved to this folder by default. When you print a custom report with **13-4 Report Printer**, it looks to the \\ServerName\Sage100Contractor\Custom Reports folder for the list of custom reports.

Note: For the custom report to appear in Sage 100 Contractor, it must be saved with a similar naming scheme to reports in the area of the program where you want it to appear.

Sage 100 Contractor system reports reserve numbers 21 and higher, so the report name must use 20 or lower. These reports are shared by all companies on the same computer or can be shared with other computers.

You may want to create a custom report and keep it in this folder for testing. After the report is working as you expect, you may want to rename it and move it to the \System Reports folder so that it is available within the program on the appropriate print menu. These reports are shared by all companies on the same computer or can shared with other computers.
