You are here: [Glossary](Glossary.md) > administrator password

Before logging in to License Administration the first time as the **Administrator**, you must set and enter the administrator password using the **Logon Administrator Password** window.

Important! We recommend that you write your **Administrator** password down and keep it in a convenient place. If you forget it, it can only be re-established through contact with Customer Support at 800-866-8049.
