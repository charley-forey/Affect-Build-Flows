You are here: [Glossary](Glossary.md) > user name

User name is the name with which you log in to a Sage product such as Sage 100 Contractor.

User names define access to Sage 100 Contractor companies and must be set up for a Sage 100 Contractor company by a company administrator. Every time you create a new company, you have to create a list of user names on the **7-2-2 User List**window.
