You are here: [Glossary](Glossary.md) > Report Forms (private) folder

All system reports must have a corresponding system form. You can open a system form and create a custom form. When you save it, you have to save it to the \\ServerName\Sage100Contractor\User Data\username\Report Forms folder and name it with a similar naming scheme and the exact same file extension for the form to appear where you expect it.

For example:

- System form for **3-4 Statements**: **System.Statement_Job**
- Custom Form Name: **CustomForm1.Statement_Job**
