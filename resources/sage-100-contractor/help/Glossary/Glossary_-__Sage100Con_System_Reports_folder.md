You are here: [Glossary](Glossary.md) > System Reports folder

This folder contains both locked and modifiable reports.

- **Locked Reports**—All default system reports are stored in the \Program Files (x86)\Sage\Sage 100 Contractor SQL\System Reports folder. Some of the over 1100 system report are "locked," that is, you cannot modify the data portion of the report. In certain cases, however, some of the reports allow some modification of the design.
- **Modifiable Reports**—If you open a system report and save it with a different name, it is saved to the Program Files (or \Program Files (x86)\Sage\Sage 100 Contractor SQL\System Reports folder by default. However, you can save it in a different folder.

To display a report saved with a different name in Sage 100 Contractor, it must be saved with a similar naming scheme and with a number less than 21. Sage 100 Contractor reserves numbers 21 and higher for system reports, so the report name must use 20 or lower.

These reports are shared by all companies on the same computer or can be shared with other computers. For example:

- System Report file name for 3-1-1: **03010121 – Job List**
- Custom Report file name for 3-1-1: **03010102 – Custom Job List**
