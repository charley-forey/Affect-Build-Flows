You are here: [Glossary](Glossary.md) > \\ServerName\Sage100Contractor\Report Forms folder

All system reports must have a corresponding system form. You can open a system form and create a custom form. When you save it, you must save it to the \\ServerName\Sage100Contractor\Report Forms folder and name it using the naming scheme and the exact file extension for the form to appear where you expect it.

For example:

- System form for **3-4 Statements**: **System.Statement_Job**
- Custom Form Name: **CustomForm1.Statement_Job**
