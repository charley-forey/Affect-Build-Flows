### Creating queries

#### To create a query:

|  | 1 | On the **File** menu, click **Find**. |
|---|---|---|

|  | 2 | Click **New**. |
|---|---|---|

|  | 3 | In the **Name** box, enter the name of the query. |
|---|---|---|

|  | 4 | Using the **Query Wizard**, create the query. |
|---|---|---|

Tip: After you create a query, Sage 100 Contractor automatically saves it.
