### Using the calculators stored memory

You can store a figure in the calculator’s memory for use in future calculations.

| To | Do this |
|---|---|
| Place a number in memory | Click the **Memory** button. |
| Recall a number in memory | Click the **Recall** button. |
| Add a number to memory | Click the **M+** button. |
| Remove a number from memory | Click the **M–** button. |
