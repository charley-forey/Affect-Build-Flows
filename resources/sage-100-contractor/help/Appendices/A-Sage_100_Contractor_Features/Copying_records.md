### Copying records

You can copy existing records to create new records, which saves time and prevents errors that can result from entering complex transactions.

#### To copy a record:

|  | 1 | Using the data control, select the record. |
|---|---|---|

|  | 2 | From the **Edit** menu, select **Copy**. |
|---|---|---|

|  | 3 | From the **File** menu, select **New**. |
|---|---|---|

|  | 4 | From the **Edit** menu, select **Paste**. |
|---|---|---|

Note: Sage 100 Contractor copies all notes attached to the record.
