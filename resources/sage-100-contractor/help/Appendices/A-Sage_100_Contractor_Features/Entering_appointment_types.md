### Entering appointment types

#### To enter appointment types:

|  | 1 | Open the calendar. |
|---|---|---|

|  | 2 | On the menu bar, click **Appointment Types**. |
|---|---|---|

|  | 3 | In the **Appointment#** cell, enter the appointment number. |
|---|---|---|

|  | 4 | In the **Description** cell, enter a description for the type of appointment. |
|---|---|---|

|  | 5 | Repeat steps 3–4 for each type. |
|---|---|---|

|  | 6 | From the **File** menu, select **Save**. |
|---|---|---|
