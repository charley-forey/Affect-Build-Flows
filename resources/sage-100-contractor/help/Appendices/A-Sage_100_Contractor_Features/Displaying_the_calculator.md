### Displaying the calculator

You can display the calculator from any window, cell or box by pressing F3. The calculator displays the results in a list similar to a calculator tape.

From within some numeric-entry cells in a grid there are several ways to display the calculator.

To display the calculator, do one of the following:

- Enter a number followed by an operator.
- Press F3.
