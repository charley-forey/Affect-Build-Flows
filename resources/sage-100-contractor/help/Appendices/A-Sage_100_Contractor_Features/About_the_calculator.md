## Working with the Calculator

You can display the calculator from any window, cell or box by pressing F3. The calculator displays the results in a list similar to a calculator tape. When you use the calculator, you can paste the results to the selected cell or box in the active window.

From within some numeric-entry cells in a grid there are several ways to display the calculator.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To display the calculator, do one of the following](javascript:void(0);)

- Enter a number followed by an [operator](../../Modules/13-Review_and_Reporting/About_operators.md).
- Press F3.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To perform calculations](javascript:void(0);)

1. Select the cell or box in the active window, and [open the calculator](Displaying_the_calculator.md).
2. Enter the first number in the calculation.
3. Click an [operator](../../Modules/13-Review_and_Reporting/About_operators.md).
4. Enter the next number in the calculation.
5. Click **Enter**.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To paste from the calculator, do one of the following](javascript:void(0);)

- Click the check mark button next to the **Entry**, **Memory**, or **Total** boxes.
- Use the **Copy** and **Paste** commands.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To convert measurements on the calculator](javascript:void(0);)

1. Open the calculator.
2. Enter the number you want to convert.
3. On the **Conversions** menu, point to **Standard**, **US to Metric**, **Metric to US**, or **Pitch** and select the type of conversion you want.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To select the number of decimal places](javascript:void(0);)

- Under **Places**, select the option for the number of decimal places you want.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To store a figure in the calculator’s memory for use in future calculations](javascript:void(0);)

| To | Do this |
|---|---|
| Place a number in memory | Click the **Memory** button. |
| Recall a number in memory | Click the **Recall** button. |
| Add a number to memory | Click the **M+** button. |
| Remove a number from memory | Click the **M–** button. |
