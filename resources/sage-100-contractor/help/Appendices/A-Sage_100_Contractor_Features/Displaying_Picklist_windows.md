### Displaying Picklist windows

#### To display a Picklist window, do one of the following:

- From the grid cell of a column that supports **Picklist** functionality, for example **Part#** or **Assembly#**, right-click a cell, and then click **Display Picklist Window**.
- A window related to that column opens with **Picklist** functionality indicated by the check mark button.
- From the grid cell of a column that supports **Picklist** functionality, press F8. Important! If you press F8 on a criteria item that displays a **Picklist** check mark, such as in the **5-2-3 Compute Payroll** window, no **Picklist** window is displayed. The F5 key, however, displays the **Picklist** window.
- From windows with text boxes that support **Picklist** functionality, such as **5-2-3 Compute Payroll**, click the check mark button.
