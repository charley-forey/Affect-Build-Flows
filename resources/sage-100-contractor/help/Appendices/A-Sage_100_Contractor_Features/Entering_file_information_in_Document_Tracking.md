### Entering file information in Document Tracking

Document Tracking provide a way for you to track file information associated with a record.

#### To enter file information:

|  | 1 | On the **Options** menu, click **Document Tracking**. |
|---|---|---|

|  | 2 | In the **Document** column, enter the name of the document. |
|---|---|---|

|  | 3 | In the **Copies** column, enter the number of copies sent. |
|---|---|---|

|  | 4 | In the **Return** column, you can indicate whether the document has been returned or not. Type Yes if the document has been returned, or No if the document is still out. |
|---|---|---|

|  | 5 | In the **Note** column, double-click a cell and type a note as required. |
|---|---|---|

|  | 6 | On the **File** menu, click **Save**. |
|---|---|---|
