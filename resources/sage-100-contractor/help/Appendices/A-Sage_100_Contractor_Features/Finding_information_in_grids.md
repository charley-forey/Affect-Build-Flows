### Finding information in grids

#### To find information in a grid:

|  | 1 | Right-click in a grid to display the grid menu. (See links) |
|---|---|---|

|  | 2 | Click **Find** on the grid menu. |
|---|---|---|

|  | 3 | In the **Grid Find** dialog box, choose the scope of your search by selecting either **Current Column** or **Entire Grid**. |
|---|---|---|

|  | 4 | In the **Search For** cell, type the text string you want to find. |
|---|---|---|

|  | 5 | Click **Find Next** to find the next occurrence of the text string. |
|---|---|---|
