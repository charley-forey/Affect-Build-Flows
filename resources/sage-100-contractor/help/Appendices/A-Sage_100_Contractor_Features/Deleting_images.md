### Deleting images

#### To delete an image:

|  | 1 | Using the data control, select the record from which you want to delete an image. |
|---|---|---|

|  | 2 | On the **Edit** menu, click **Image**. |
|---|---|---|

|  | 3 | Click **Clear**. |
|---|---|---|

|  | 4 | Click **OK**. |
|---|---|---|
