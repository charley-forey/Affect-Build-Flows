# About Custom Fields

If you are a company administrator, you can define custom fields for most Sage 100 Contractor records, except for ledger transactions, accounts, daily payroll, and recurring transactions.

Sage 100 Contractor does not limit the number of custom fields that you can define for a particular window or for your Sage 100 Contractor company.

There are new custom-fields related windows:

- Custom Fields. If you have rights to use a Sage 100 Contractor window, you use the Custom Fields window to view or to enter values for custom fields that have been added to a parent window. If you log on as a company administrator, you can click the [**Add**] or [**Modify**] buttons to open additional windows where you add new custom fields or modify existing ones.
- Custom Field Properties. If you log on as a company administrator, you can use this window to add, edit, and delete custom fields.

Windows that provide custom fields have a **Custom Fields** option on the Edit menu, and a new [**Enter Optional Fields**] button on the toolbar. When you click the **Edit > Custom Fields** option or the [**Enter Custom Fields**] button:

- If custom fields have been defined for the parent window, the **Custom Fields** window opens.
- If no custom fields have been defined for a window, the **Custom Field Properties** window opens.
