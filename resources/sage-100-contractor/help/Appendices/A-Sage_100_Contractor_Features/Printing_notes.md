### Printing notes

If you want to move the location where notes print on a document, you can modify the form design. (See links)

Important! When you create a note in a **Report Printing** window, the note appears on all documents.

Important! Some notes print with specific reports; other notes function as memos to a specific topic and can only be printed from the notes window itself.

To print a note, in the **Report Printing** window, select the **Notes**or **Grid Notes** check boxes.
