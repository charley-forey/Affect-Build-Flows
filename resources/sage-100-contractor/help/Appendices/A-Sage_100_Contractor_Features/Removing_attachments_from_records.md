### Removing attachments from records

You can remove local and linked files as well as Web page links by clicking Remove on the **Attachments for...** window.

Notes:

- If you attempt to open a linked network file that has been moved or deleted, the program displays a message stating that the file cannot be found.
- To delete attachments, you must belong to a security group that has rights to delete records.
