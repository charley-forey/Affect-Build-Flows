# Locking records

Select the **Lock Edit** check box to prevent accidental changes to a record after saving it. To make permanent changes, clear the **Lock Edit** check box and save the record.

You can find the **Lock Edit** check box in budgets, proposals, estimates, purchase orders, change orders, and subcontracts. In cases where a calculation is being performed, the calculation will include locked data, even though it cannot be edited.

Tip: Use the display properties to allow certain security groups the ability to clear the check box once a record is saved.
