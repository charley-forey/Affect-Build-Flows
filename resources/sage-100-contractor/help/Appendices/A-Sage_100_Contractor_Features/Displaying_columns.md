### Displaying columns

Under certain circumstances, columns are hidden from view. Use this procedure to display hidden columns.

#### To display hidden columns:

|  | 1 | Right-click in a cell, and from the menu select **Show/Hide Columns**. (See links) |
|---|---|---|

|  | 2 | The **Grid View** window appears. |
|---|---|---|

|  | 3 | From the menu, select the check boxes of the columns you want to display. |
|---|---|---|

|  | 4 | Click **OK**. |
|---|---|---|
