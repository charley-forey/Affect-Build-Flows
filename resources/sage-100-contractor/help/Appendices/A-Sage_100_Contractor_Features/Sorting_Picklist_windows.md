### Sorting Picklist windows

In fields that contain character or alphanumeric data such as descriptions, addresses, and invoice numbers, Sage 100 Contractor sorts data by the value of the first digit.

If a field is strictly numeric, the numbers appear in numerical order. For example, 1100 appears before 200.

To sort a column in ascending order, click the arrow in the column title.
