# Query Wizard: Layout the Query's Report

|  | 1 | To select fields from the Primary Table, double-click on fields from the Fields list on the top right. Each field is added to the bottom panel. |
|---|---|---|

These fields can be sorted by name if you select the option to **List Fields by Name**.

|  | 2 | If you need to select fields that are not in the primary table, select a related table on the top left that contains the field(s) you want to add to the report, then double-click on the fields that you need. |
|---|---|---|

Note: If you add fields that can be totaled, the total is automatically placed on the report when the report is generated.

|  | 3 | In the bottom panel, you can do the following actions: |
|---|---|---|

|  | a | Add grouping to the report by dragging columns to the group area in the dark gray band. A maximum of three fields can be used for grouping. |
|---|---|---|

|  | b | Add sorting by left-clicking on a column. The number that appears next to the column name is the next consecutive number after the last group. If no groups are defined, the sort column displays a 1. You can have multiple sorts in the main column row by holding the shift key when clicking additional columns. |
|---|---|---|

|  | c | Reorder columns by dragging them to a different location. |
|---|---|---|

|  | d | Remove columns from the report by right-clicking them. |
|---|---|---|
