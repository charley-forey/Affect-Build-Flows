# Custom Field Properties window

Note: You must be a company administrator to open this window.

You use the Custom Field Properties window to add, edit, or delete custom fields for a Sage 100 Contractor record. You can define custom fields for most Sage 100 Contractor records, except for ledger transactions, accounts, daily payroll, and recurring transactions.

#### To open the Custom Field Properties window:

1. Click **Edit > Enter Custom Fields**, or click the **Enter custom fields**![](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Content/Resources/Images/CustomFieldsBtn.png) button on the taskbar, If no custom fields have been defined for the window, the Custom Field Properties window appears immediately. If any custom fields are defined for the window, the **Custom Field** entry window appears.
2. If the **Custom Field** entry window appears, you can still modify an existing field or add a new custom field, providing you are logged in as a Company Administrator. If you want to modify an existing field, click the field, and then either: If you want to add a new custom field, click [**Add**].
   
   - Press F7, or
   - Click [**Modify**], and then on the **Modify Custom Fields** window, click the **Edit properties for this field**![](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Content/Resources/Images/EditFieldProperties_Btn.png) button.
