### Deleting appointments

#### To delete an appointment:

|  | 1 | Open the calendar. |
|---|---|---|

|  | 2 | Select the day of the appointment. |
|---|---|---|

|  | 3 | On the menu bar, click **Edit**, then click **Appointments**. |
|---|---|---|

|  | 4 | Select the appointment. |
|---|---|---|

|  | 5 | Press the Delete key. |
|---|---|---|
