## Initializing the Act! database for use with Sage 100 Contractor

Before you can use the Sage 100 Contractor integration, you must initialize the Act! database.

Important! You can initialize a database only if you are an Act! Administrator or Manager user.

#### To initialize the Act! database:

1. Log into Act!. When entering an Act! database that has not been initialized, you are prompted to initialize the database for use with Sage 100 Contractor.
2. Click [**Yes**] to initialize the database.
3. Restart Act!.

Note: A **Sage 100 Contractor** tab is visible in [**Companies**] and [**Opportunities**] after initializing the database.
