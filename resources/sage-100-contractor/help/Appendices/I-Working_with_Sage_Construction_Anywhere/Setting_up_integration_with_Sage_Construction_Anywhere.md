## Setting up Sage Construction Anywhere Integration

To integrate Sage 100 Contractor with Sage Construction Anywhere, you must first install and set up the following programs:

- Sage 100 Contractor 2016 version 20.5
- The most recent build of Sage Construction Anywhere

In addition, an API user needs to be set up for any companies that are to be integrated.

- In Sage 100 Contractor, in **7-2-1 Security Groups**, an API security group must exist with the appropriate save permissions. See [Setting up an API security group and an API user in Sage 100 Contractor](Setting_up_an_API_security_group_and_an_API_user_in_Sage_100_Contractor.md) to set up the API group.
- In Sage 100 Contractor, in **7-2-2 User List**, a user that is a member of the API group must be set up.
