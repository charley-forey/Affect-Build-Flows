### Windows 7 and changing the Sage License Server computer

On a Windows 7 workstation, when you select **File > Change Sage License Server > Select the computer from the list of computers on your network**, the command may fail to generate a list of network computer names.

To resolve this issue, click **Enter the IP address or name of the computer**, and then type the IP address of the server computer in the box.
