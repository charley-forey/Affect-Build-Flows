### Windows 7 and Server 2008 or Server 2008 R2 installation and mapped drives

Mapped drives may not be available when installing on a computer running the Windows 7 or Server 2008 operating systems. See the Microsoft knowledgebase article about allowing mapped drives to display elevated users: [http://support.microsoft.com/kb/937624/](http://support.microsoft.com/kb/937624/)
