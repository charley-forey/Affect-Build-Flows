### Windows 7 network configuration and TCP Remoting Channel

Sage 100 Contractor uses the TCP Remoting Channel, a Microsoft .NET Framework component to enable communication among computers on a network. File sharing on computers running the Windows 7 or Server 2008 operating system must be enabled.

To enable file sharing, follow the instructions in the Windows 7 or Server 2008 Help.
