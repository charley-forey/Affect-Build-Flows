### Reprinting accounts payable cheques

#### To reprint an accounts payable cheque:

|  | 1 | Void the cheque. |
|---|---|---|

|  | 2 | Open **4-3 Vendor Payments**. |
|---|---|---|

|  | 3 | Select the invoices for payment. |
|---|---|---|

|  | 4 | Set the invoice you want to pay. |
|---|---|---|

|  | 5 | Print the cheque. |
|---|---|---|
