### About 4-3-3 EFT Payment File Manager

When you open **4-3-3 EFT Payment File Manager**, you can retract an EFT payment batch. This removes all vendor payment records associated with that batch number, and voids the associated general ledger payment.

On the Options menu, you can also print reports using the **Print EFT Payment File Report** and **Reprint or Email EFT Payment Email Receipts**.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To retract an EFT payment batch](javascript:void(0);)

|  | 1 | Open **4-3-3****EFT****Payment File Manager**. |
|---|---|---|

|  | 2 | In the **Batch#** field, enter the payment batch you would like to retract. |
|---|---|---|

|  | 3 | Click [**Yes**] to confirm that you want to retract these payments now. |
|---|---|---|

Note: If you click [**No**] in this dialog box, the **EFT** payment batch will not be retracted.

Sage 100 Contractor confirms that the EFT payment batch retract process is complete.

|  | 4 | Click [**OK**]. |
|---|---|---|
