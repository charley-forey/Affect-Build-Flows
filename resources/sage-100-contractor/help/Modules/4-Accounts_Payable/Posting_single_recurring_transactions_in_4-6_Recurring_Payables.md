### Posting single recurring transactions in 4-6 Recurring Payables

Important! If you want to post to a different period, you must change the posting period.

#### To post a single recurring transaction:

|  | 1 | Open **4-6 Recurring Payables**. |
|---|---|---|

|  | 2 | Select the transaction. |
|---|---|---|

|  | 3 | On the **Post** menu, click **This Invoice Only.** |
|---|---|---|
