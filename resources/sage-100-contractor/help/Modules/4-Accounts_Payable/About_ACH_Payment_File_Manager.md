### About EFT Payment File Manager

When you create an EFT Payment file, information is recorded for vendors who have authorized EFT payments to their accounts. After the file is created, transfer the file using your bank’s specified procedure.

Important! Before creating an EFT Payment file, you must first establish a procedure with your bank for transferring the file.

When you create a new company, an EFT Payment File folder is created within the company folder.

The default file name is set to the cheque date and vendor name. Invalid characters (/ \:*?"<>|) in the file name will be stripped out by Sage 100 Contractor.
