### Printing separate cheques per invoice by vendor

When you enter a vendor or edit a vendor’s information, you can specify that you want the system to print separate cheques per invoice for that vendor when you pay them.

#### To print separate cheques per invoice by vendor:

|  | 1 | Open **4-4 Vendors (Accounts Payable)**, and select a vendor. |
|---|---|---|

|  | 2 | Select the **Separate Cheques** check box. |
|---|---|---|

|  | 3 | On the file menu, click **File** > **Save**. |
|---|---|---|
