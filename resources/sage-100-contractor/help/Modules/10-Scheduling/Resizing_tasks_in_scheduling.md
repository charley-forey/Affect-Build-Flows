### Resizing tasks in scheduling

#### To resize a task:

|  | 1 | Open **10-3 Schedules**. |
|---|---|---|

|  | 2 | Using the data control, select an existing schedule and click the **Grid/Gantt** button. |
|---|---|---|

|  | 3 | In the **Mode** menu, select **Resize Tasks**. |
|---|---|---|

|  | 4 | Drag the right end of the task to the desired position. |
|---|---|---|
