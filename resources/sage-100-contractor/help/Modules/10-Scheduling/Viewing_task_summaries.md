### Viewing task summaries

In Gantt view, you can display a summary of information related to a particular task.

#### To view a task summary:

|  | 1 | Open **10-3 Schedules**. |
|---|---|---|

|  | 2 | Using the data control, select an existing schedule and click the **Grid/Gantt** button. |
|---|---|---|

|  | 3 | Position the pointer over a task, then right-click. |
|---|---|---|
