### Importing scheduling files

When you import a file, the file writes over any data already contained in the grid.

#### To import a scheduling file:

|  | 1 | Open **10-3 Schedules**. |
|---|---|---|

|  | 2 | In the data control box, enter the job number. |
|---|---|---|

|  | 3 | In the **Phase** list, select the phase. |
|---|---|---|

|  | 4 | On the **Options** menu, point to **Import**, then click **Schedule File**. |
|---|---|---|

|  | 5 | Select the file that you want to import. |
|---|---|---|

|  | 6 | Click **OK**. |
|---|---|---|
