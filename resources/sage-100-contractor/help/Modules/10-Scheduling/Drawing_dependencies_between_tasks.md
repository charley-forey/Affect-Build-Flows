### Drawing dependencies between tasks

#### To draw dependencies between tasks:

|  | 1 | Open **10-3 Schedules**. |
|---|---|---|

|  | 2 | Using the data control, select an existing schedule and click the **Grid/Gantt** button. |
|---|---|---|

|  | 3 | On the **Mode** menu, click **Draw Predecessors**. |
|---|---|---|

|  | 4 | Click the start or finish of a task, and then drag to the start or finish of another task. |
|---|---|---|

Tips:

- Connect a task to a predecessor, moving from the bottom to the top of the Gantt chart.
- You can assign task dependencies between jobs.
