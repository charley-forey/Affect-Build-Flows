### Displaying schedule recaps

#### To display a recap:

|  | 1 | Open **10-3 Schedules**. |
|---|---|---|

|  | 2 | On the **Options** menu, select **Recap**. |
|---|---|---|

|  | 3 | Under **View jobs with the following status**, select or clear any of following check boxes: |
|---|---|---|

|  | n | 1-Bid |
|---|---|---|

|  | n | 3-Contract |
|---|---|---|

|  | n | 4-Current |
|---|---|---|

|  | 4 | From the options **Week**, **Month**, **Quarter**, or **Year**, select the period you want to view. |
|---|---|---|
