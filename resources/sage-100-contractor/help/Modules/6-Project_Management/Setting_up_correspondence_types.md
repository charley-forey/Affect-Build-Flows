### Setting up correspondence types

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

#### To set up correspondence types:

|  | 1 | Open **6-11-8 Correspondence**. |
|---|---|---|

|  | 2 | Next to the **Type** drop-down list on the right side of the window, click the **Add/View Records** button. |
|---|---|---|

|  | 3 | In the **Correspondence Type#** cell, enter the type number. |
|---|---|---|

|  | 4 | In the **Type Name** cell, enter a description of the type. |
|---|---|---|

|  | 5 | On the **File** menu, click **Save**. |
|---|---|---|
