### Deleting change orders

#### To delete a change order:

|  | 1 | Open **6-4-1 Change Orders**. |
|---|---|---|

|  | 2 | Using the data control, select the record. |
|---|---|---|

|  | 3 | On the **Edit** menu, click **Delete Change Order**. |
