### Entering and tracking a set of plans

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

#### To enter and track a set of plans:

|  | 1 | Open **6-11-5 Plan Records**. |
|---|---|---|

|  | 2 | Do the following: |
|---|---|---|

|  | a | In the **Plan#** box, enter the revision number. |
|---|---|---|

|  | b | In the **Job** box, enter the job number. |
|---|---|---|

|  | c | If the job uses phases, enter the phase number in the **Phase** box. |
|---|---|---|

|  | d | In the **Date** box, enter the date. |
|---|---|---|

|  | e | In the **Description** box, enter a brief statement about the set of plans. |
|---|---|---|

|  | f | In the grid, in the **Description** cell, enter a brief statement about the plan revisions. |
|---|---|---|

|  | 3 | On the **File** menu, click **Save**. |
|---|---|---|
