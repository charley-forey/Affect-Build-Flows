### Deleting field reports

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

#### To delete a field report:

|  | 1 | Open **6-11-6 Daily Field Reports**. |
|---|---|---|

|  | 2 | Using the data control, select the record. |
|---|---|---|

|  | 3 | On the **Edit** menu, click **Delete Daily Report**. |
|---|---|---|
