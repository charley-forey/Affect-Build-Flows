### Deleting proposals

#### To delete a proposal:

|  | 1 | Open **6-9 Proposals**. |
|---|---|---|

|  | 2 | Using the data control, select the record. |
|---|---|---|

|  | 3 | On the **Edit** menu, click **Delete Proposal**. |
|---|---|---|
