### Entering the percentage of hours completed on jobs

#### To enter the percentage of hours completed on a job:

|  | 1 | Open **6-8-2 Hours to Complete**. |
|---|---|---|

|  | 2 | Using the data control, select the job. |
|---|---|---|

|  | 3 | In the **Phase** list, click the phase. |
|---|---|---|

Note: You must select and update each phase separately.

|  | 4 | On the menu bar, click **Update**. |
|---|---|---|

|  | 5 | Select a cost code. |
|---|---|---|

|  | 6 | In the **Actual Percent** cell, enter the hours of work actually completed. |
|---|---|---|

|  | 7 | Repeat steps 5–6 for each cost code. |
|---|---|---|

|  | 8 | Edit the record if necessary. |
|---|---|---|

|  | 9 | On the **File** menu, click **Save**. |
|---|---|---|
