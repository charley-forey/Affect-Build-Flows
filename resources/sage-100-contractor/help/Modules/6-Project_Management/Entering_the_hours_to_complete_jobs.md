### Entering the hours to complete jobs

#### To enter the hours to complete a job:

|  | 1 | Open **6-8-2 Hours to Complete**. |
|---|---|---|

|  | 2 | Using the data control, select the job. |
|---|---|---|

|  | 3 | In the **Phase** list, click the phase. |
|---|---|---|

You must select and update each phase separately.

|  | 4 | On the menu bar, click **Update**. |
|---|---|---|

|  | 5 | Select a cost code. |
|---|---|---|

|  | 6 | In the **Hours to Complete** cell, enter the remaining hours to complete the work. |
|---|---|---|

|  | 7 | Repeat steps 6–7 for each cost code. |
|---|---|---|

|  | 8 | Edit the record if necessary. |
|---|---|---|

|  | 9 | On the **File** menu, click **Save**. |
|---|---|---|
