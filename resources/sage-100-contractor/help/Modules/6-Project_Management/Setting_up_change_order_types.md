### Setting up change order types

You can create a list of change order types, allowing you to categorize change orders. A general contractor, for example, might create types to track contract changes, internal changes, and back charges to subcontractors.

The following is an example of change order types:

| CO Type # | Type Name |
|---|---|
| 10 | Field Engineering |
| 20 | Architect Initiated |
| 30 | Field Request |
| 70 | Sub Backcharge |
| 80 | Cross Charge |
| 90 | Internal Request |

#### To set up change order types:

|  | 1 | Open **6-4-1 Change Orders**. |
|---|---|---|

|  | 2 | Next to the **Type** list, click the detail button. |
|---|---|---|

|  | 3 | In the **CO Type#** cell, enter the type number. |
|---|---|---|

|  | 4 | In the **Type Name** cell, enter a description of the change order type. |
|---|---|---|

|  | 5 | Repeat steps 2–4 for each type. |
|---|---|---|

|  | 6 | On the **File** menu, click **Save**. |
|---|---|---|
