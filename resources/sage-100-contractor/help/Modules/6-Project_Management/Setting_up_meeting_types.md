### Setting up meeting types

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

You can create meeting types to classify conferences. The following is an example of meeting types:

| Meeting Type | Description |
|---|---|
| 1 | Field Personnel Meeting |
| 2 | On-Site Safety Meeting |
| 11 | On-Job Owner/Architect |
| 19 | Punch List |

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To set up meeting types](javascript:void(0);)

|  | 1 | Open **6-11-6 Daily Field Reports**. |
|---|---|---|

|  | 2 | Using the data control, select the record. |
|---|---|---|

|  | 3 | On the **Options** menu, click **Meetings**. |
|---|---|---|

|  | 4 | In a **Meeting Type** cell, right-click, then click **Display Detail/Add Record**. |
|---|---|---|

|  | 5 | The **Meeting Type** window appears. |
|---|---|---|

|  | 6 | In the **Type#** cell, enter the meeting type number. |
|---|---|---|

|  | 7 | In the **Type Name** cell, enter a description of the meeting type. |
|---|---|---|

|  | 8 | Repeat steps 6–7 for each type. |
|---|---|---|

|  | 9 | On the **File** menu, click **Save**. |
|---|---|---|
