### Importing proposal files

#### To import a proposal file:

|  | 1 | Open **6-9 Proposals**. |
|---|---|---|

|  | 2 | In the data control box, enter the job number of the job for which you want to create a proposal. |
|---|---|---|

|  | 3 | On the **Options** menu, point to **Import**, then click **Proposal File**. |
|---|---|---|

|  | 4 | Select the file that you want to import, and click **OK**. |
|---|---|---|

Important! When you import a file, the file writes over any data already contained in the grid.
