### Setting up RFI types

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

You can create a list of RFI types, allowing you to categorize the RFIs. The following is an example of RFI types:

| RFI Type # | Type Name |
|---|---|
| 1 | Initial Request |
| 2 | Second Request |
| 3 | Change Request |

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To set up RFI types](javascript:void(0);)

|  | 1 | Open **6-11-2 Requests for Information**. |
|---|---|---|

|  | 2 | Next to the **RFI Type** list, click the detail button. |
|---|---|---|

|  | 3 | In the **RFI Type#** box, enter the type number. |
|---|---|---|

|  | 4 | In the **Type Name** box, enter a description of the type. |
|---|---|---|

|  | 5 | On the **File** menu, click **Save**. |
|---|---|---|
