### Setting the original budget

When you set the original budget, Sage 100 Contractor copies the budget information to the **Original** columns. With the original budget preserved, you can compare it to the current budget. The original budget information is for reference only.

#### To set the original budget:

|  | 1 | Create the budget. |
|---|---|---|

|  | 2 | On the **Options** menu, click **Set Budget**. |
