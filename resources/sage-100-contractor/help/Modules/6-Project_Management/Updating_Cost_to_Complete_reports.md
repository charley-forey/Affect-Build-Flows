### Updating Cost to Complete reports

#### To update a Cost to Complete report:

|  | 1 | Open **6-8-1 Cost to Complete**. |
|---|---|---|

|  | 2 | Using the data control, select the job. |
|---|---|---|

|  | 3 | In the **Phase** list, click the phase. You must select and update each phase separately. |
|---|---|---|

|  | 4 | On the **Options** menu, click **Update**. |
|---|---|---|
