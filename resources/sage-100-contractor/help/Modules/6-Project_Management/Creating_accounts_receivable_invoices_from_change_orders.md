### Creating accounts receivable invoices from change orders

You can create accounts receivable invoices from the **6-4-1 Change Orders** window.

Important! The change order status must be **1-Approved** to use this function.

#### To create an accounts receivable invoice from a change order:

|  | 1 | Open **6-4-1 Change Orders**. |
|---|---|---|

|  | 2 | Select the change order. |
|---|---|---|

|  | 3 | On the **Options** menu, click **Create A/R Invoice**. |
|---|---|---|
