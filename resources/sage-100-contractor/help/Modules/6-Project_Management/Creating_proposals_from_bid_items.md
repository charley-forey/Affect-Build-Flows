### Creating proposals from bid items

#### To create a proposal from bid items:

|  | 1 | Open **6-9 Proposals**. |
|---|---|---|

|  | 2 | Using the data control, select the job. |
|---|---|---|

|  | 3 | If the job uses phases, in the **Phase** drop-down list, select the phase. |
|---|---|---|

|  | 4 | Select **Use Bid Items for proposal lines**. |
|---|---|---|

|  | 5 | In the **Bid Items** cell, right-click, then click **Display Picklist Window**. |
|---|---|---|

|  | 6 | Create a **Picklist** of bid items, and click the check mark button to insert them into the grid. |
|---|---|---|

|  | 7 | For each bid item, enter the proposed amounts (including the overhead and profit) for each cost type. |
|---|---|---|

|  | 8 | Set the original proposal. |
|---|---|---|

|  | 9 | On the **File** menu, click **Save**. |
|---|---|---|
