### Setting up submittal types

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

The following is an example of submittal types:

| Submittal Type # | Type Name |
|---|---|
| 1 | Material Supplier |
| 4 | Subcontractor |

|  | 1 | Open **6-11-4 Submittals**. |
|---|---|---|

|  | 2 | Next to the **Type** list, click **View/Add records**. |
|---|---|---|

|  | 3 | In the **Submittal Type#** box, enter the type number. |
|---|---|---|

|  | 4 | In the **Type Name** box, enter a description of the type. |
|---|---|---|

|  | 5 | On the **File** menu, click **Save**. |
|---|---|---|
