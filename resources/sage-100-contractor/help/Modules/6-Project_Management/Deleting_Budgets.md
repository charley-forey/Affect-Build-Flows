### Deleting budgets

#### To delete a budget:

|  | 1 | Open **6-2 Budgets**. |
|---|---|---|

|  | 2 | Using the data control, select the record. |
|---|---|---|

|  | 3 | On the **Edit** menu, click **Delete Budget**. |
|---|---|---|
