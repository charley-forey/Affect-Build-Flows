### About displaying subcontract descriptions

When creating a change order that affects a subcontract, you can display the subcontract description under the **Subcontract** column in the **Budget and Sub Changes Details** tab.

When you select the **Display Subcontract Desc.** command on the **Options** menu, Sage 100 Contractor displays the subcontract description after the subcontract record number and the subcontract number.
