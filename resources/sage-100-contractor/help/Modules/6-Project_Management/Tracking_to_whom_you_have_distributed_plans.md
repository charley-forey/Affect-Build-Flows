### Tracking to whom you have distributed plans

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

You can enter the date when the plans were returned in the **Date Returned** column.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To track to whom you have distributed plans](javascript:void(0);)

|  | 1 | Open **6-11-5 Plan Records**. |
|---|---|---|

|  | 2 | Using the data control, select the record. |
|---|---|---|

|  | 3 | On the **Options** menu, click **Plan Distribution**. |
|---|---|---|

|  | 4 | In the **Subcontractor** box, enter the vendor number of the subcontractor to whom you provided a set of plans. |
|---|---|---|

|  | 5 | In the **Contact** box, enter the name of the contact person. |
|---|---|---|

|  | 6 | In the **Copies** box, enter the number of copies sent. |
|---|---|---|

|  | 7 | In the **Date Sent** box, enter the date when you sent the plans. |
|---|---|---|

|  | 8 | On the **File** menu, click **Save**. |
|---|---|---|
