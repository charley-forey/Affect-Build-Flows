### Displaying and printing budget cost code or phases recaps

|  | 1 | Open **6-2 Budgets**. |
|---|---|---|

|  | 2 | Using the data control, locate a job. |
|---|---|---|

|  | 3 | From the **Options** menu, select **Recap** and one of the following: |
|---|---|---|

- **Cost Codes**
- **Phases**

|  | 4 | On the **Budget Recap** window, click the **Print records** button. |
|---|---|---|

|  | 5 | On the **Grid Printing** window, click **Preview report on screen** or **Print Records**. |
|---|---|---|
