### Setting up RFP types

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

You can create a list of Request for Proposal types, allowing you to categorize the RFPs. The following is an example of Request for Proposal types:

| Request Type # | Type Name |
|---|---|
| 1 | Materials |
| 2 | Equipment |
| 3 | Subcontract |
| 4 | Other |

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To set up RFP types](javascript:void(0);)

|  | 1 | Open **6-11-1 Requests for Proposal**. |
|---|---|---|

|  | 2 | Next to the **Type** list, click the detail button. |
|---|---|---|

|  | 3 | The **RFP Types** windows appears. |
|---|---|---|

|  | 4 | In the **Request Type#** box, enter the type number. |
|---|---|---|

|  | 5 | In the **Type Name** box, enter the type name. |
|---|---|---|

|  | 6 | On the **File** menu, click **Save**. |
|---|---|---|
