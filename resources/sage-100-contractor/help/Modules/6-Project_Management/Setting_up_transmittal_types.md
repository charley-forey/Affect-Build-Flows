### Setting up transmittal types

Note: This functionality is available only if you have the [Document Control Module](http://www.na.sage.com/sage-100-contractor/modules/project-management).

You can create a list of transmittal types, allowing you to categorize the transmittals. The following is an example of transmittal types:

| Transmittal Type # | Type Name |
|---|---|
| 10 | Job Startup |
| 20 | Mid-Project Update |
| 30 | Job Closeout |

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To set up transmittal types](javascript:void(0);)

|  | 1 | Open **6-11-3 Transmittals**. |
|---|---|---|

|  | 2 | Next to the **Type** list, click the detail button. |
|---|---|---|

|  | 3 | In the **Transmittal Type#** box, enter the type number. |
|---|---|---|

|  | 4 | In the **Type Name** box, enter a description of the type. |
|---|---|---|

|  | 5 | On the **File** menu, click **Save**. |
|---|---|---|
