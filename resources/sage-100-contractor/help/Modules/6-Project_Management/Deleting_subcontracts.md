### Deleting subcontracts

Important! You cannot delete a subcontract record if it already has an invoiced or changed amount. You cannot delete a grid line if it already has an invoiced or changed amount.

#### To delete a subcontract:

|  | 1 | Open **6-7-1 Subcontracts**. |
|---|---|---|

|  | 2 | Using the data control, select the record. |
|---|---|---|

|  | 3 | On the **Edit** menu, click **Delete Subcontract**. |
|---|---|---|
