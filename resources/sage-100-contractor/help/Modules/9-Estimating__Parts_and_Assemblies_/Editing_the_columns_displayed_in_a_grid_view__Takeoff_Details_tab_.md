### Editing the columns displayed in a grid view (Takeoff Details tab)

Note: This functionality is available only if you have the [Estimating Module](http://www.na.sage.com/sage-100-contractor/modules/estimating).

You can temporarily change which columns display in a specific grid view on the **Takeoff Details** tab.

#### To edit the columns displayed in a grid view:

|  | 1 | Open **9-5 Takeoffs**, and click the **Takeoff Details** tab. |
|---|---|---|

|  | 2 | Right-click in a grid cell. |
|---|---|---|

|  | 3 | Do the following: |
|---|---|---|

|  | a | Select the check boxes by columns you want to display. |
|---|---|---|

|  | b | Clear the check box by the columns you want to hide. |
|---|---|---|

|  | 4 | Click **OK**. |
|---|---|---|
