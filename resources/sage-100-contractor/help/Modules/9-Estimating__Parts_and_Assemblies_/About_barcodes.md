### About barcodes

Complete functionality is only available if you have purchased the [Estimating Add-On Module](http://na.sage.com/sage-100-contractor/modules/estimating).

Note: This functionality is available only if you have the [Inventory Add-On Module](http://www.na.sage.com/sage-100-contractor/modules/service-management).

Sage 100 Contractor uses the part record number for the barcode. You can also use barcodes to track inventory if you have the **Inventory** add-on module.
