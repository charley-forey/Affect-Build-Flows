### Viewing the inventory for parts

Complete functionality is only available if you have purchased the [Estimating Add-On Module](http://na.sage.com/sage-na/eula).

This functionality is only available if you have the [Inventory Add-On Module](http://na.sage.com/sage-100-contractor/modules/service-management).

#### To view the inventory for a part:

|  | 1 | Open **9-2 Parts**. |
|---|---|---|

|  | 2 | Using the data control, select the part. |
|---|---|---|

|  | 3 | Click the **Inventory** button. |
|---|---|---|

Tip: To view the inventory for a different part, use the data control.
