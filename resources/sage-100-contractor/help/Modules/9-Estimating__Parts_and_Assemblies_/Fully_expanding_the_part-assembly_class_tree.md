### Fully expanding the part-assembly class tree

Complete functionality is only available if you have purchased the [Estimating Add-On Module](http://na.sage.com/sage-100-contractor/modules/estimating).

Assembly functionality is only available if you have purchased the [Estimating Add-On Module](http://na.sage.com/sage-100-contractor/modules/estimating) or [Service Receivables Add-On Module](http://na.sage.com/sage-100-contractor/modules/service-management).

**Fully Expand** is a command available both on the **Part/Assembly Edit**menu and from the right-click menu. This feature opens every sub-class below it.

#### To fully expand the part/assembly class tree:

|  | 1 | In the **9-4 Part/Assembly Classes** window, click a part class to select it. |
|---|---|---|

|  | 2 | Do one of the following: |
|---|---|---|

- On the **Edit** menu, click **Fully Expand**.
- On the right-click menu, click **Fully Expand**.
