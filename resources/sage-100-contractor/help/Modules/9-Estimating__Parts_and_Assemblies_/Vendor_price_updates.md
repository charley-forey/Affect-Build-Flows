# Vendor price updates

#### To update vendor prices:

|  | 1 | In the **Vendor** drop-down list, select the vendor that you want to update. |
|---|---|---|

|  | 2 | In the **Price** column, enter the per part price for each part that you want to update. |
|---|---|---|

|  | 3 | Click **Update**. |
|---|---|---|

Note: Parts for the selected vendor display in part number order.
