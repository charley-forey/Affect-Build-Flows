### Indenting part-assembly classes

Complete functionality is only available if you have purchased the [Estimating Add-On Module](http://na.sage.com/sage-100-contractor/modules/estimating).

Assembly functionality is only available if you have purchased the [Estimating Add-On Module](http://na.sage.com/sage-100-contractor/modules/estimating) or [Service Receivables Add-On Module](http://na.sage.com/sage-100-contractor/modules/service-management).

**Indent** is a command available both on the **Part/Assembly Edit** menu and from the right-click menu. This feature builds sub-classes by moving the selected class to the right. If the class has “children” or sub-classes, you will be asked whether you want to include them in the move.

#### To indent a part/assembly class:

|  | 1 | Open **9-4 Part/Assembly Classes**. |
|---|---|---|

|  | 2 | Click a part class to highlight it. |
|---|---|---|

|  | 3 | Select **Indent** from the **Edit** menu or the right-click menu. |
|---|---|---|

Note: The right arrow button also indents the class.
