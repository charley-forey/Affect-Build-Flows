### Customizing the priority dropdown list

You can customize the eight selections in the priority dropdown list in **11-2 Work Orders/Invoices/Credits** to make it applicable to your workflow. When you look at the appointment on the **Dispatch Board**, its priority appears as a color in the upper right corner.

#### Example #1: Priority by Service Level Agreement

For example, if you want to assign priority by service level agreement, you can do the following:

| Priority | Color |
|---|---|
| 1-4 Hour Response Time | Red |
| 2-Same Day Response | Orange |
| 3-8 Hour Response Time | Yellow |
| 4-24 Hour Response Time | Green |
| 5-48 Hour Response Time | Gray |

#### Example #2: Priority by County

| Priority | Color |
|---|---|
| West County | Red |
| North County | Yellow |
| East County | Green |
| South County | Blue |

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To customize the priority dropdown list](javascript:void(0);)

1. Open **11-2 Work Orders/Invoices/Credits**.
2. Click the **Dispatch** tab.
3. Click the up arrow to the right of the priority dropdown list.
4. In the **Label and Prompt** tab:
   
   1. Type a name for the Priority label in the User Description field. Use only letters or numbers, up to 19 characters, spaces included.
   2. Type a prompt to help you identify what information the User Description field. This information displays in the status bar.
5. In the **Item Names and Colors** tab:
   
   1. Type text in the fields to customize your section names.
   2. To change the color for the section name, click the lookup button to the right.
6. If you need to remove a section or insert a section:
   
   1. Click the [**Advanced Options**] link.Note: You must be a company administrator to access the Advanced Options area.
   2. Delete the unneeded sections. If a section name is assigned to a record, you cannot delete that section.
7. Click [**OK**].

The changes are reflected in the Section Name and dropdown menu.
