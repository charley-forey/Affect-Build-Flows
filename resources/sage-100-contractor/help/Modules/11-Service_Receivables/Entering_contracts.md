### Entering contracts

Note: Service Receivables features are available only if you have purchased the [Service Receivables Add-On Module](http://na.sage.com/sage-100-contractor/modules/service-management).

#### To enter a service contract:

|  | 1 | Open **11-2 Work Orders/Invoices/Credits**. |
|---|---|---|

|  | 2 | In the **Order#** text box, enter the order number. |
|---|---|---|

|  | 3 | In the **Date** text box, enter the date of the **invoice**. |
|---|---|---|

|  | 4 | In the **Client#** text box, enter a dummy client number. |
|---|---|---|

|  | 5 | In the **Description** text box, enter a brief statement about the transaction. |
|---|---|---|

|  | 6 | In the **Job** text box, enter the job number. |
|---|---|---|

|  | 7 | In the **Status** list, click **10-Contract**. |
|---|---|---|

|  | 8 | In the **Type** list, click the invoice type. |
|---|---|---|

|  | 9 | You may also do the following, if applicable: |
|---|---|---|

|  | a | If you want to enter the customer or client location, [enter the data](Entering_locations_on_a_work_order.md) on the **Location** tab. |
|---|---|---|

|  | b | If you want to schedule the service call, [enter the data](Scheduling_service_calls_on_a_work_order.md) on the **Dispatch** tab. |
|---|---|---|

|  | c | If you want to enter the parts or assemblies necessary to complete the work, [enter the data](Entering_invoice_details_for_service_calls.md) on the **Invoice Details** tab. |
|---|---|---|

|  | 10 | On the **File** menu, click **Save**. |
|---|---|---|

Tip: You can use markups and overrides when entering a new contract. (See links)
