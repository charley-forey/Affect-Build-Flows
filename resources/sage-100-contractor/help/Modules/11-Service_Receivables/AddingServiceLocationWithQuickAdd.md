# Adding a new service location for a client

Using the grid in the to add a location for a client can be slow, especially if there are many existing locations.

The **11-2 Work Orders/Invoices/Credits** provides a separate **Add Service Location** window, where you can quickly add a new location for a client.

If you select the **Create New Locations with Quick Add** option from the Options menu, Sage 100 Contractor will prompt you to use the new window when you enter a new **Location** code.

Note: You must display a client in the **11-2 Work Orders/Invoices/Credits** window before you can use the **Add Client Location** screen.

#### Use the following methods to display the **Add Client Location** window:

- In the **Client Location** lookup window, click the **Quick Add** button.
- If the **Create New Locations with Quick Add** option is selected, enter a new **Location** code, and then click **Yes** at the message asking if you want to create a new record.
