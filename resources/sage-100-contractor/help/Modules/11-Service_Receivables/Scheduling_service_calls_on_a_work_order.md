# Scheduling service calls on a work order

Note: Service Receivables features are available only if you have purchased the [Service Receivables Add-On Module](http://na.sage.com/sage-100-contractor/modules/service-management).

The **Payroll Records** window uses service orders to create timecards. Sage 100 Contractor looks at the grid on the **Dispatch** tab for the date work is completed and the actual number of hours worked.

Important! If you want a Work Order to display on the dispatch board as "Unassigned," do not fill in the grid on the **Location** and **Dispatch** tab. If you do fill in the grid, an employee number is required for the Work Order to display on the dispatch board.

#### To schedule a service call:

|  | 1 | Open **11-2 Work Orders/Invoices/Credits**. |
|---|---|---|

|  | 2 | Click the **Dispatch** tab. |
|---|---|---|

|  | 3 | Under **Date/Time**, do the following: |
|---|---|---|

|  | a | In the first **Call** text box, enter the date when you received the call. In the second **Call** text box, enter the time when you received the call. |
|---|---|---|

|  | b | In the first **Dispatched** text box, enter the date when you dispatched the call. In the second **Dispatch** text box, enter the time when you dispatched the call. |
|---|---|---|

|  | c | In the first **Scheduled** text box, enter the date when the work is to be performed. In the second **Scheduled** text box, enter the time when the work is to be performed. |
|---|---|---|

|  | d | In the **Estimated Hours** text box, enter the estimated number of hours necessary to complete the work. |
|---|---|---|

|  | e | In the first **Started** text box, enter the date when the actual work begins. In the second **Started** text box, enter the time when the actual work begins. |
|---|---|---|

|  | f | In the first **Completed** text box, enter the date when the actual work is completed. In the second **Completed** text box, enter the time when the actual work is completed. |
|---|---|---|

|  | g | In the **Actual Hours** text box, enter the actual number of hours necessary to complete the work. |
|---|---|---|

|  | h | In the **Priority** cell, enter the priority number reflecting the need for the employee. |
|---|---|---|

|  | i | In the **Technician** text box, enter the employee number. |
|---|---|---|

|  | 4 | In the grid, do the following: |
|---|---|---|

|  | a | In the **Employee** cell, enter the employee number. |
|---|---|---|

|  | b | In the **Equipment** cell, enter the equipment number of equipment used on the service call. |
|---|---|---|

|  | c | In the **Priority** cell, enter the priority of the call. |
|---|---|---|

|  | d | In the **Sched. Date** cell, enter the date when the employee is scheduled to begin. |
|---|---|---|

|  | e | In the **Sched. Start** cell, enter the time when the employee is scheduled to begin. |
|---|---|---|

|  | f | In the **Sched. Finish** cell, enter the time when the employee is scheduled to finish. |
|---|---|---|

|  | g | In the **Sched. Hours** cell, enter the estimated number of hours necessary to complete the work. |
|---|---|---|

|  | h | In the **Travel Time** cell, enter the travel time in minutes. |
|---|---|---|

|  | i | In the **Completed Date** cell, enter the date when the work is completed. |
|---|---|---|

|  | j | In the **Actual Start** cell, enter the time when the actual work begins. |
|---|---|---|

|  | k | In the **Actual Finish** cell, enter the time when the actual work is completed. |
|---|---|---|

|  | l | In the **Actual Hours** cell, enter the actual number of hours necessary to complete the work. |
|---|---|---|

|  | m | In the **Billed Date** cell, enter the date when you billed for the work. |
|---|---|---|

|  | 5 | Repeat step 4 for each employee, for each day worked. |
|---|---|---|
