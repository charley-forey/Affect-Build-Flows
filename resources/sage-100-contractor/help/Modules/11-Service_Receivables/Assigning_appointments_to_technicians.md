### Assigning appointments to technicians

Note: Service Receivables features are available only if you have purchased the [Service Receivables Add-On Module](http://na.sage.com/sage-100-contractor/modules/service-management).

#### To assign an appointment to a technician:

|  | 1 | Open **11-2 Work Orders/Invoices/Credits**. |
|---|---|---|

|  | 2 | From the **Options** menu, select **Dispatch Board**. |
|---|---|---|

|  | 3 | Using the data control, select the day you want to view. |
|---|---|---|

|  | 4 | In the **Unassigned** column, find the work order. |
|---|---|---|

|  | 5 | Drag the work order to the time and employee that you want. |
|---|---|---|
