### Entering setup data for unitary bills

In order to create a unitary bill, you have to provide some basic information in the **Unitary Billing Setup** window, such as the name of the architect, the architect’s job number for the project, the income posting account, and the holdback rate.

#### To enter setup data for a unitary bill:

|  | 1 | Open **3-9 Unitary Billing** and click the **Setup** button at the bottom left. |
|---|---|---|

|  | 2 | In the **Unitary Billing Setup** window, in the **Architect** text box, enter the vendor number of the architect or engineer. |
|---|---|---|

|  | 3 | In the **Architect’s Job#** text box, enter the number the architect uses to refer to the job. |
|---|---|---|

|  | 4 | In the **Income Account** text box, enter the income account. |
|---|---|---|

|  | 5 | If you are using subsidiary accounts, enter the account number in the **Subaccount** text box. |
|---|---|---|

|  | 6 | In the **Holdback Rate** text box, enter the rate of holdback. |
|---|---|---|

|  | 7 | On the menu bar, click **Save**. |
|---|---|---|
