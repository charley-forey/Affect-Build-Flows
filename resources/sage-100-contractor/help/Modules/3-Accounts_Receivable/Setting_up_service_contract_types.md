### Setting up service contract types

If you perform service work, you can categorize the types of service contracts you fulfill.

#### [![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)Example 1: Service contract types using projects](javascript:void(0);)

| Contract # | Description |
|---|---|
| 1 | Time and Materials Projects |
| 2 | Progress Billing Projects |
| 3 | Government Projects |

#### [![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)Example 2: Service contract types using time increments](javascript:void(0);)

| Contract # | Description |
|---|---|
| 1 | Weekly |
| 2 | Monthly |
| 3 | Bi-monthly |
| 4 | Semi-yearly |
| 5 | Yearly |

#### To set up service contract types:

|  | 1 | Open **3-6 Receivable Clients**. |
|---|---|---|

|  | 2 | Select the client. |
|---|---|---|

|  | 3 | On the **Options** menu, click **Service Contracts**. |
|---|---|---|

|  | 4 | Next to the **Type** list, click the detail button. |
|---|---|---|

|  | 5 | In the **Contract#** text box, enter the number. |
|---|---|---|

|  | 6 | In the **Description** text box, enter a brief statement about the type of contract. |
|---|---|---|

|  | 7 | Repeat steps 5–6 for each type. |
|---|---|---|

|  | 8 | On the **File** menu, click **Save**. |
|---|---|---|
