### Releasing holdback for unitary bills

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To release holdbacks for a unitary bill](javascript:void(0);)

|  | 1 | Open **3-9 Unitary Billing**. |
|---|---|---|

|  | 2 | Select the record for which you want to release the holdbacks. |
|---|---|---|

|  | 3 | On the **Options** menu, click **Setup**. |
|---|---|---|

|  | 4 | In the **Holdback Rate** text box, delete the rate. |
|---|---|---|

|  | 5 | On the **File** menu, click **Save**. |
|---|---|---|

|  | 6 | In the **Holdback Rate** column in the grid, delete the rate. |
|---|---|---|

|  | 7 | On the **Options** menu, click **Calculate**. |
|---|---|---|

|  | 8 | On the **File** menu, click **Save**. |
|---|---|---|

|  | 9 | Create the holdback billing in accounts receivable. |
|---|---|---|
