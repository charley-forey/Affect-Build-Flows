### Setting up receivable client product lines

In the **Client Product Line** window, you can set up a list of the different products you supply.

#### To set up client product lines:

|  | 1 | Open **3-6 Receivable Clients**. |
|---|---|---|

|  | 2 | Click the **Sales and Marketing** tab. |
|---|---|---|

|  | 3 | Next to the **Product** drop-down, click the detail button. |
|---|---|---|

|  | 4 | In the **Product#** text box, enter the product number. |
|---|---|---|

|  | 5 | In the **Description** text box, enter a brief statement about the product. |
|---|---|---|

|  | 6 | Repeat steps 4–5 for each product. |
|---|---|---|

|  | 7 | On the **File** menu, click **Save**. |
|---|---|---|
