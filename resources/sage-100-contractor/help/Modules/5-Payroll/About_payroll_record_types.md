### About payroll record types

The payroll record type indicates what kind of payroll record you are entering.

| Type | Description |
|---|---|
| 1-Regular | A record timecard entry. |
| 2-Bonus | A lump sum paid to an employee. |
| 3-Hand Computed | An adjusting entry made to the payroll calculation balances in an employee record. |
| 4-Start Up | An entry that is not journalized. |
| 5-Advance | An entry that advances funds to an employee. |
| 6-Third Party | Third-party sick pay. |
