### Calculation type 5-Accrued Hours

You can use calculation type **5-Accrued Hours** to create a calculation that builds up hours. For example, you could use this calculation to keep track of hours used to determine an employee’s vacation time.

A payroll calculation that uses calculation type **5-Accrued Hours** does not post to the general ledger or create job costs.

For information on setting up a calculation for accrued vacation pay, see [About accruing vacation pay](About_accruing_vacation_amounts.md).
