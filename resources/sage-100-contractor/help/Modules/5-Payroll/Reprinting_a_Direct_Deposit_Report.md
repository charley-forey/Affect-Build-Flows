### Reprinting a Direct Deposit Report

You can reprint the direct deposit report by following the instructions below. The report is printed from a direct deposit TXT file.

To reprint a direct deposit report:

|  | 1 | Open **5-2-5 Direct Deposit File Manager**. |
|---|---|---|

|  | 2 | From the **Options** menu, select **Reprint Direct Deposit Report**. |
|---|---|---|

|  | 3 | On the **Select the Direct Deposit File** window, select the direct deposit file that you want to reprint as a report, and click **Open**. |
|---|---|---|

|  | 4 | After the program validates the file, it is sent to the printer. |
|---|---|---|

Important! As required by business needs, you can set up security to restrict access to this option.
