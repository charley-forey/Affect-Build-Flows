### Changing the default bank account when posting payroll

#### To change the default bank account when posting payroll:

1. Log in as Administrator.
2. Open **5-2-4 Report Printing**window, and click **Print**.
3. On the **Cheques Printing** window, click the **Payroll Chequing Account** box once, and then press F7.
4. On the **Field Properties** window, enter the chequing account number in the **Default Entry** box and then click **OK**.

Each time you run payroll cheques, the system will default to the account you selected.
