### Changing the pay period from weekly to biweekly

#### To change the pay period from weekly to bi-weekly:

|  | 1 | Open **5-2-1 Employees**. |
|---|---|---|

|  | 2 | Display an employee. |
|---|---|---|

|  | 3 | Click the **Compensation** tab. |
|---|---|---|

|  | 4 | From the **Pay Period** menu, select **Bi-Weekly**. |
|---|---|---|

|  | 5 | Select **File** > **Save**. |
|---|---|---|

|  | 6 | Repeat Steps 1 through 5 for each employee. |
|---|---|---|
