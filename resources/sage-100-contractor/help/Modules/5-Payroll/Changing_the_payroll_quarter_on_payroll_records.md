### Changing the payroll quarter on payroll records

#### To change the payroll quarter on a payroll record:

|  | 1 | Open **5-2-2 Payroll Records**. |
|---|---|---|

|  | 2 | Using the data control, select the payroll record. |
|---|---|---|

|  | 3 | In the **Quarter** text box, enter the correct quarter number. |
|---|---|---|

|  | 4 | On the **File** menu, click **Save**. |
|---|---|---|
