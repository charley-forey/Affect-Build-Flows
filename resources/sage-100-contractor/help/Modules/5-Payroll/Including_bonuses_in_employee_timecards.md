### Including bonuses in employee timecards

#### To include a bonus in an employee’s timecard:

|  | 1 | Enter the timecard for the employee. |
|---|---|---|

|  | 2 | On a separate timecard line, do the following: |
|---|---|---|

|  | a | In the **Description** cell, enter a brief statement about the bonus. |
|---|---|---|

|  | b | If you want to job cost the bonus, enter the job number in the **Job** cell. |
|---|---|---|

|  | c | If the job requires certified payroll, type Yes in the **Certified** cell. |
|---|---|---|

|  | d | If the job uses phases, enter the phase number in the **Phase** cell. |
|---|---|---|

|  | e | If the employee worked on a job, enter the cost code number in the **Cost Code** cell. |
|---|---|---|

|  | f | In the **Pay Type** cell, click **9-Miscellaneous**. |
|---|---|---|

|  | g | In the **Pay Rate** cell, enter the amount of the bonus. |
|---|---|---|

|  | h | In the **Compensation Code** cell, enter the Workers’ Compensation code number. |
|---|---|---|

|  | i | If you are using departments, enter the department number in the **Department** cell. |
|---|---|---|

|  | 3 | On the **File** menu, click **Save**. |
|---|---|---|
