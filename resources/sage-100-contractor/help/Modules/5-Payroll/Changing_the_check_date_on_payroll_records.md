### Changing the cheque date on payroll records

#### To change the cheque date on a payroll record:

|  | 1 | Open **5-2-2 Payroll Records**. |
|---|---|---|

|  | 2 | Using the data control, select the payroll record. |
|---|---|---|

|  | 3 | In the **Cheques Date** text box, enter the correct cheque date. |
|---|---|---|

|  | 4 | On the **File** menu, click **Save**. |
|---|---|---|
