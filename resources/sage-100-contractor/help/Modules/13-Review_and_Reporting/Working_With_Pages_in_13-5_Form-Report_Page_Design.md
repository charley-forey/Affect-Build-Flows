### Working with pages in 13-5 Form/Report Page Design

In the **Pages** menu, you can do the following page options:

- Adding new pages
- Inserting new pages
- Copying pages
- Pasting pages
- Removing pages

Note: When you add a page, the page is automatically added as the last page. If you want to control where a page is added, use the **Insert Page** selection under the **Pages** menu.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To add a new page](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, on the **Pages** menu, click **Add Page**. |
|---|---|---|

|  | 2 | Click **Save**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To insert a new page](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, display the page above which you want to insert a new page. |
|---|---|---|

|  | 2 | From the **Pages** menu, click **Insert Page**. |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To copy a page](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, select the page you want to copy. |
|---|---|---|

|  | 2 | From the **Pages** menu, click **Copy Page**. |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To paste a page](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, select the page to paste a copied page to. |
|---|---|---|

|  | 2 | From the **Pages** menu, click **Paste Page**. |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To remove a page](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, display the page that you want to remove. |
|---|---|---|

|  | 2 | On the **Pages** menu, click **Remove Page**. |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|
