### Modifying existing reports to create new reports

To locate the report you want to open, you need to know the name of the report. The file name is a combination of:

- The menu option where the report is located
- The number of the report.

These two items are combined to form an eight-character file name, for example, 04010221.RPF, is the report that corresponds to **4-1-2 Payable Invoice**, report 21.

#### To modify an existing report to create a new report:

1. Open **13-3 Report Writer**.
2. From the New Report Launch wizard, select **Browse for an existing report...**, and locate the \Program Files (or Program Files (x86))\Sage\Sage 100 Contractor\System Reports folder.

Note: Both locked and open reports are included in the System Reports folder, but only open reports can be modified.

|  | 1 | Alternatively, you can open the report that you want to modify by locating the report on a Report Printing window, selecting it, and then clicking **Modify Report** button. |
|---|---|---|

|  | 2 | From the list, locate and double-click the report you want to open, for example, 04010221.RPF. |
|---|---|---|

|  | 3 | Type a new report title in the **Title** text field. |
|---|---|---|

|  | 4 | Select a report form for the **Form** text field. |
|---|---|---|

|  | 5 | To modify the grouping and sorting of field, select **Edit > Grouping/Sorting...**. |
|---|---|---|

|  | 6 | On the **Define Grouping and Sorting** window, choose a table, double-click items in the **Fields** list to move them to the bottom panel. |
|---|---|---|

In the bottom panel, you can do the following:

|  | a | Remove groups by right-clicking a group field |
|---|---|---|

|  | b | Reorder groups by dragging them into the desired order |
|---|---|---|

|  | c | Change sorting by clicking on columns in the main row of the panel |
|---|---|---|

|  | 7 | Click **OK**. |
|---|---|---|

|  | 8 | To modify the selection criteria, select **Edit > Selection Criteria...** . |
|---|---|---|

|  | a | On the **Define the Selection Criteria** window, choose a table, double-click items in the **Fields** list to move them to the bottom panel. |
|---|---|---|

|  | b | In the bottom panel, you can choose to enter default criteria, or you can leave the criteria blank. |
|---|---|---|

|  | c | Click **OK**. |
|---|---|---|

|  | 9 | From the **File** menu, select **File > Save**. |
|---|---|---|

|  | 10 | To the message box confirming the modification, click **OK**. |
|---|---|---|

|  | 11 | Change the last two digits of the report name to a number between 1 and 20. |
|---|---|---|

|  | 12 | Select **Save**. |
|---|---|---|
