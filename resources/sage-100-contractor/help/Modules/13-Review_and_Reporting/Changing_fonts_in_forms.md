### Changing fonts in forms

#### To change fonts:

|  | 1 | In **13-5 Report/Form Page Design**, open the form in which you want to change fonts. |
|---|---|---|

|  | 2 | Highlight the field or fields that need font changes. |
|---|---|---|

|  | 3 | From the **Edit** menu, click **Font**. |
|---|---|---|

|  | 4 | In the **Font** window, select the **Font**, **Font style**, **Size**, and **Effects** as needed. |
|---|---|---|

|  | 5 | Click **OK**. |
|---|---|---|
