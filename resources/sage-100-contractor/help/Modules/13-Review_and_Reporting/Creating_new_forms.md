### Creating new forms

To create a new form, open **13-5 Form Report/Page Design**. The **13-5 Form Report/Page Design** window appears, displaying a blank page on which you can begin creating your new form.

Tip: If you have to make only a few changes or additions to a form, it can be quicker to create a new form from an existing one than to create a form from scratch.
