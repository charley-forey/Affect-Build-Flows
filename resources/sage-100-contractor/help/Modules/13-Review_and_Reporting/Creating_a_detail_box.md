### Creating a detail box

The detail box determines where the body of the report appears on a form design when you generate the report.

#### To create a detail box:

|  | 1 | In **13-5 Form/Report Page Design**, open the form in which you want to create a detail box. |
|---|---|---|

|  | 2 | On the **Insert** menu, click **Detail**. |
|---|---|---|

|  | 3 | Click in the location where you want to place one corner of the detail box and drag the pointer diagonally to the size you want. |
|---|---|---|
