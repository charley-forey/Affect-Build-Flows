### About label forms

Sage 100 Contractor provides several form designs for mailing labels in the **Jobs**, **Clients**, **Vendors**, and **Employee Document** windows. You can use these designs with Avery #5160 laser labels. For tractor feed labels, use the **DMLabel1** design.

- In the **Vendor Documents** window, you can print company return address labels using the Avery 5160 form designs.
- Using **Form/Report Page Design**, you can create form designs to print labels for envelopes, file folders, floppy disks, and so on.
