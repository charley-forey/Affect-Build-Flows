### Setting the form or line color in reports

#### To set the form or line color:

|  | 1 | In **13-3 Report Writer**, on the **Edit** menu, click **Color**. |
|---|---|---|

|  | 2 | Click the color you want to use or define a custom color. |
|---|---|---|

|  | 3 | Click **OK**. |
|---|---|---|

#### To set or change the text object color:

|  | 1 | In **13-3 Report Writer**, select the text object. |
|---|---|---|

|  | 2 | Select **Edit > Color**. |
|---|---|---|

|  | 3 | Click the color you want to use or define a custom color. |
|---|---|---|

|  | 4 | Click **OK**. |
|---|---|---|

Note: Changing the color affects both text and graphics that you draw after the change.
