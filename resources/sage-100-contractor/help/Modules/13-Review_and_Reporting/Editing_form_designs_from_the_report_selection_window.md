### Editing form designs from the report selection window

You can edit form designs from the **Report Printing** window by following this procedure.

#### To edit a form design from the report selection window:

|  | 1 | From the **Report Printing** window, click the **Print Records** button. |
|---|---|---|

|  | 2 | Select **Edit > Form Design**. |
|---|---|---|

|  | 3 | On the **13-5 Form/Report Page Design** window, edit the form. |
|---|---|---|

|  | 4 | Select **File > Save**. |
|---|---|---|

|  | 5 | Return to the **Report Printing** window. |
|---|---|---|

|  | 6 | You can use the modified design immediately with a document that you want to print. |
|---|---|---|
