### Working with global calculated fields

Global calculated fields are a good way to copy a calculation from one report to another. Many pre-defined calculations are in the **Global Calculated Fields** list, but not all.

A global calculated field is a type of field representing an expression. When you generate a report, Sage 100 Contractor determines the result of the calculated field based on information stored in the databases. After creating a global calculated field, you can add it to the list of calculated fields available for use in the design.
