### Typing text in reports

#### To type text:

|  | 1 | In **13-3 Report Writer**, open the report in which you want to type text. |
|---|---|---|

|  | 2 | On the **Insert** menu, click **Text**. |
|---|---|---|

|  | 3 | Click where you want to place the text. |
|---|---|---|

|  | 4 | Type the text you want to enter. |
|---|---|---|
