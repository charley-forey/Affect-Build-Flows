### Working with text in 13-5 Form/Report Page Design

You can use the following text options in forms :

- Typing text
- Editing text
- Checking the spelling
- Changing fonts
- Aligning text

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To type text](javascript:void(0);)

|  | 1 | In **13-5 Report/Form Page Design**, open the form in which you want to type text. |
|---|---|---|

|  | 2 | Click where you want to place the text. |
|---|---|---|

|  | 3 | Type the text you want to enter. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To edit text](javascript:void(0);)

|  | 1 | In **13-5 Report/Form Page Design**, open the form in which you want to edit text. |
|---|---|---|

|  | 2 | Double click on the field you want to edit and make the changes that you want. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To check the spelling](javascript:void(0);)

|  | 1 | In **13-5 Report/Form Page Design**, open the form in which you want to check spelling. |
|---|---|---|

|  | 2 | From the **Edit** menu, click **Spell Check**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To change fonts](javascript:void(0);)

|  | 1 | In **13-5 Report/Form Page Design**, open the form in which you want to change fonts. |
|---|---|---|

|  | 2 | Highlight the field or fields that need font changes. |
|---|---|---|

|  | 3 | From the **Edit** menu, click **Font**. |
|---|---|---|

|  | 4 | In the **Font** window, select the **Font**, **Font style**, **Size**, and **Effects** as needed. |
|---|---|---|

|  | 5 | Click **OK**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To align text](javascript:void(0);)

|  | 1 | In **13-5 Report/Form Page Design**, open the form in which you want to align text. |
|---|---|---|

|  | 2 | Click the text that you want to align. |
|---|---|---|

|  | 3 | From the **Edit** menu, click **Align Left** or **Align Right**, as needed. |
|---|---|---|

Note: The text aligns itself to where the text begins, and not the margin.
