### Creating new reports

Note: Sometimes it is quicker to create a new report by editing an existing report that needs only a few changes or additions. [How?](CreatingNewReportByModifyingExisting.md)

#### To create a new report:

1. Open **13-3 Report Writer**.
2. On the **New Report Launch** window, select one of the following options:
   
   - **Create a new report using the wizard...**
   - **Start with a blank report**
3. Click [**OK**].
