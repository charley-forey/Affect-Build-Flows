## Define Grouping and Sorting

If you open an existing report, or create a new report by starting with a blank report, you can define grouping and sorting of the fields on the report.

- Add grouping to the report by double clicking on the fields in the top right. A maximum of three fields can be used for grouping.
- Reorder group fields by dragging them to a different location.
- Remove group fields from the report by right-clicking them.
- Add sorting by clicking on a column. The number that appears next to the column name is the next consecutive number after the last group you selected. If no groups are selected, the sort column displays a 1.
