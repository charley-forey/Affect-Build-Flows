### Inserting page breaks

#### To insert a page break:

|  | 1 | In **13-3 Report Writer**, open the report into which you want to insert a page break. |
|---|---|---|

|  | 2 | In the **New Page** list, click the type of band that you want to begin a new page when printing the report. You can choose from the following options: |
|---|---|---|

- Automatic
- On Detail
- On Group1
- On Group2
- On Group3

Note: When you create a new report design, there are no page breaks. Use the page break to determine when Sage 100 Contractor prints information on the next page of a multi-page form design.
