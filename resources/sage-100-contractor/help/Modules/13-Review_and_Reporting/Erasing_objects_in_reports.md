### Erasing objects in reports

#### To erase an object:

|  | 1 | In **13-3 Report Writer**, open the report in which you want to erase an object. |
|---|---|---|

|  | 2 | Click the object or text block that you want to erase. |
|---|---|---|

|  | 3 | Right-click on the object or text block, then click **Delete**. |
|---|---|---|
