### Editing global calculated fields

#### To edit a global calculated field:

|  | 1 | In either **13-3 Report Writer** or **13-5 Form/Report Page Design**, select **Edit > Calculated Fields**. |
|---|---|---|

|  | 2 | In the **Calculated Fields** window, select the calculation from **Select Global Calculation**. |
|---|---|---|

|  | 3 | Make the changes you want to the expression. |
|---|---|---|

|  | 4 | Make changes to the **Name** and **Description** if necessary. |
|---|---|---|

|  | 5 | To save the global calculation, click **Save to Global Calculations**. |
|---|---|---|

|  | 6 | To save the global calculation to the current report, click **Save**. |
|---|---|---|

|  | 7 | Click **Close**. |
|---|---|---|
