### Moving selections in forms

When you select an object such as a box, all objects in the box move with it.

#### To move a selection:

|  | 1 | In **13-5 Form/Report Page Design**, open the form in which you want to move a selection. |
|---|---|---|

|  | 2 | Select the item you want to move. |
|---|---|---|

Note: To move multiple selections at the same time, hold down the [**Ctrl**] key and drag the mouse over the objects to be selected.

|  | 3 | Drag the selection to the desired location. |
|---|---|---|
