### Changing fonts in reports

#### To change fonts:

|  | 1 | In **13-3 Report Writer**, open the report in which you want to change fonts. |
|---|---|---|

|  | 2 | Select the field or fields that need font changes. Multiple field objects can be selected by pressing the **Ctrl**key while clicking on field objects. |
|---|---|---|

|  | 3 | On the **Edit** menu, click **Font**. |
|---|---|---|

|  | 4 | In the **Font** list, click the font. |
|---|---|---|

|  | 5 | In the **Font Style** list, click the format of the font. |
|---|---|---|

|  | 6 | In the **Size** list, click the font size. |
|---|---|---|

|  | 7 | In the **Effects** section, click **Strikeout** or **Underline** as needed. |
|---|---|---|

|  | 8 | Click **OK**. |
|---|---|---|

Note: Font features can also be changed by right clicking on a field or text object and selecting Properties.
