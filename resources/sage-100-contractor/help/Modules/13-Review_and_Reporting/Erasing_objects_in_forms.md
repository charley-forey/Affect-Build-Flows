### Erasing objects in forms

#### To erase an object:

|  | 1 | In **13-5 Form/Report Page Design**, open the form in which you want to erase an object. |
|---|---|---|

|  | 2 | Click the object or text block that you want to erase. |
|---|---|---|

|  | 3 | Right-click on the object or text block, then click **Delete**. |
|---|---|---|
