### Drawing lines in reports

#### To draw a line:

|  | 1 | In **13-3 Report Writer**, open the report in which you want to draw a line. |
|---|---|---|

|  | 2 | Select **Insert > Line**. |
|---|---|---|

|  | 3 | To draw a line, drag the pointer. |
|---|---|---|

Note: Lines may be drawn either horizontally or vertically, but not on any angle or diagonal.

#### Modifying line properties

|  | 1 | Select the line object using **Edit > Select Objects**. |
|---|---|---|

|  | 2 | Right-click on the line and select **Properties**. |
|---|---|---|

|  | 3 | Modify the line object properties. You can modify the following properties: |
|---|---|---|

|  | a | Line Width |
|---|---|---|

|  | b | Line Type |
|---|---|---|

|  | i | Solid |
|---|---|---|

|  | ii | Dash |
|---|---|---|

|  | iii | Dot |
|---|---|---|

|  | iv | Dot-Dash |
|---|---|---|

|  | c | Forecolor |
|---|---|---|

|  | d | Backcolor |
|---|---|---|

|  | e | Position and Size |
|---|---|---|

|  | i | Row: Sets the row number for the object |
|---|---|---|

|  | ii | Top: Sets the top position relative to the band line |
|---|---|---|

|  | iii | Left: Sets the left position relative to the left side of the page |
|---|---|---|

|  | iv | Width: Sets the width of the line |
|---|---|---|

|  | v | Height: Sets the height of the line |
|---|---|---|
