### About form and report page design layout

In the **Pages > Page Format** dialog box, you can set the following options:

- Page Size
- Margins
- Snap to Position Setting
- Disable or enable a 1/4 Inch Grid to align design elements

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To set the page size](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, on the **Pages** menu, click **Page Format**. |
|---|---|---|

|  | 2 | Under **Page Size**, enter the size of the page on which you want to base your design. |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To set the page margins](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, on the **Pages** menu, click **Page Format**. |
|---|---|---|

|  | 2 | Under **Margins**, enter the values for the page margins. |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To position objects with snap lines](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, on the **Pages** menu, click **Page Format**. |
|---|---|---|

|  | 2 | Under the **Layout Tools** section, next to **Size of snap-to-position grid**, click the arrows to select the position, up to 10/16". |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To display a quarter-inch grid](javascript:void(0);)

|  | 1 | In **13-5 Form/Report Page Design**, on the **Pages** menu, click **Page Format**. |
|---|---|---|

|  | 2 | Under the **Layout Tools** section, click **Show ¼" grid in background**. |
|---|---|---|

|  | 3 | Click **Save**. |
|---|---|---|
