# Replace default printer

If you select a report that has defaults saved for it, the Sage 100 Contractor attempts to use the default printer. If that printer cannot be found on the system, the “Replace Default Printer” window is displayed. The default printer settings are displayed as a reference. The next closest system default printer based on settings is presented, with an option to select any printer available on the system.

There are two options once you've selected the replacement printer in the **Replacement Settings** section:

- Use the selected printer in place of the report's default printer for now, but do not make any changes to any report defaults.
- Replace the old printer with the currently selected printer on all reports that have the old printer set as the default.
