### Entering the IP Address or name of the computer

One method is to enter the IP Address or name of the computer running the Sage license server.

Note: To use this method of selecting a server from the list of network computers, you have already clicked the appropriate link on the Specify Sage License Server window.

#### To enter the IP Address or name of the computer running the Sage license server:

|  | 1 | In the box, type the IP Address or name of the computer. |
|---|---|---|

|  | 2 | Click **OK**. |
