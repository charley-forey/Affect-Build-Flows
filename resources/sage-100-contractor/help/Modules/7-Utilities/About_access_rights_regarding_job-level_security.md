### About access rights regarding job-level security

If you want certain users to see the job-related information only for the jobs they manage, you can assign them to job-level security in **7-2-2 User List**. If a user is subject to job-level security, that user can see job-related information only for their own jobs.

Note: You can assign a user to job-level security only if you logged in as Administrator.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To assign a user to job-level security](javascript:void(0);)

1. Open **7-2-2 User List**.
2. Select the **Display Passwords** check box.
3. For each user:
   
   1. In the **User Name** cell, enter the user’s name.
   2. In the **Password** cell, enter a password.
   3. In the **Subject to Job Security** cell, click once in the cell, and type Y if the user is subject to job level security access.
4. Click **File** > **Save**.
5. Open **3-5 Jobs (Accounts Receivable)**.
6. Use the data control to find the job.
7. In the Contacts and Personnel tab:
   
   1. Click the **Edit list of users with security access to job** button next to the **Job Access List** text box.
   2. Select up to five users with security access to this job.
