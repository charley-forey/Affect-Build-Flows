### Changing the default printer driver

You can assign a different printer driver as the default for each report.

#### To change the default printer driver:

|  | 1 | Open the **Report Printing** window. |
|---|---|---|

|  | 2 | In the **Report Type** list, click the report to which you want to assign a printer. |
|---|---|---|

|  | 3 | In the **Printers** list, click the printer you want as the default. |
|---|---|---|

|  | 4 | On the **Default** menu, click **Save Defaults**. |
|---|---|---|

Note: For further information about printer drivers, refer to your printer manual.
