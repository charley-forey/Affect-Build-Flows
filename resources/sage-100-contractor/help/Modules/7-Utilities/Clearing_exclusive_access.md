### Clearing exclusive access

Some operations require exclusive access to a company by a single user, while many do not. Usually, you set the access when you open the company. However, if you have already opened the company, you can easily return to the **Company List** screen to change the type of access.

#### To clear exclusive access:

1. In the lower right corner of the Sage 100 Contractor main window, click the **Change Company/Access** link.
2. In the **Company List** window:
   
   1. Make sure the company you want to work with is selected.
   2. Clear the **Open company exclusively** check box.
   3. Click **Open**.

Note: If you want to log in as a different user, you must close Sage 100 Contractor completely, and then log in using a different user name.
