### Mapping a network drive to access a company

You may have to map to a network drive to access a Sage 100 Contractor company if it is not located on a drive on your local computer. Let’s suppose that the company has been moved to network drive Z: Now to access the company data, you have to map to drive Z.

#### To map a network drive:

|  | 1 | From the computer that needs a drive mapped, right-click the Microsoft Windows Start button, and then choose Explore. |
|---|---|---|

|  | 2 | From the Tools menu, select **Map Network Drive**. |
|---|---|---|

|  | 3 | In **Drive** field, accept the default drive letter or press the down arrow to assign another drive letter. |
|---|---|---|

|  | 4 | Click [**Browse**]. |
|---|---|---|

|  | 5 | Click the plus sign next to the server to display the shared directories. |
|---|---|---|

|  | 6 | Select shared folder that contains the company data that you want to map. |
|---|---|---|

|  | 7 | Click [**OK**]. |
|---|---|---|

|  | 8 | Select **Reconnect at Logon**, and then click [**Finish**[. |
|---|---|---|

|  | 9 | Open Sage 100 Contractor. From the drop-down list, select the drive letter entered in step 3. |
|---|---|---|

|  | 10 | Select the company file in the main window. |
|---|---|---|

|  | 11 | Click [**OK**]. |
|---|---|---|

If you are still unable to map a network drive after following these procedures, please contact your system administrator, or a local IT Professional.

For additional information, refer to article 308582 in Microsoft's knowledgebase.
