### Printing to file using the Generic-Text Only driver

#### To print to file using the Generic/Text only driver:

|  | 1 | On the menu bar, click **Print Records**. |
|---|---|---|

|  | 2 | In the **Report Type** list, click the report that you want to print. |
|---|---|---|

|  | 3 | In the **Printers** list, click **Generic/Text Only**. |
|---|---|---|

|  | 4 | In the **Form Design** list, click the form design that you want. |
|---|---|---|

|  | 5 | On the **Selection Criteria** tab, enter the criteria that you want to use for selecting data. |
|---|---|---|

|  | 6 | To preview the document, click the **Preview** button. |
|---|---|---|

|  | 7 | On the menu bar, click **Print Records**. |
|---|---|---|

|  | 8 | Name the file and navigate to the folder where you want to save it, then click **OK**. |
|---|---|---|
