## Setting up properties for text boxes, lists, check boxes, and columns

Using the F7 key, you can set up the default properties for almost any text box, list, check box, grid cell, or column within a window.

For example, you may want to auto-populate certain fields in a window to speed up the work. In some cases, it is essential for certain fields to be hidden from view for business purposes.

Important!

- Only company administrators can set up these properties.
- You cannot restrict access to system-required fields.

#### To set up properties for a text box or list or check box or column:

1. On the **File** menu, click **Open Company**.
2. Log in as a company administrator.
3. Navigate to the window that you want to set up or change.
4. Place your cursor in a text box or grid cell, or select a check box or column, and then press F7.
5. The **Field Properties** window appears.
6. Select the appropriate check boxes or type entries in the text boxes to set their properties.
