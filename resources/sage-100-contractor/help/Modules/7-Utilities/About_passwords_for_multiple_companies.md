### About passwords for multiple companies

Passwords help prevent users from opening the wrong company and entering data in it.

You can set up a different list of user names and passwords for each company. However, providing users altogether different passwords for each company can prove confusing.

Suppose you have three companies: Northern Contractors, Western Contractors, and Southern Contractors. Instead of creating three different passwords for each user, assign each user one password that he or she uses to access all the companies.

To prevent users from accidentally opening and entering data in the wrong company, add an abbreviation of the company name to the password. The example below illustrates the passwords for a single user to access three different companies.

| Company | Password |
|---|---|
| Northern Contractors | Bear Northern |
| Western Contractors | Bear Western |
| Southern Contractors | Bear Southern |

Important! If you use Windows authentication when setting up user access, you do not set up separate passwords for users in the **7‑2‑2 User List**. If you select Integrated Security for these users, they simply enter their Windows ID when logging into the Sage 100 Contractor company. However, you cannot assign Integrated Security to users that are set up with SQLServer authentication.
