### Sorting contacts in 7-8 Contact Manager

You can sort the contact records using the following methods:

- Sorting by column
- Sorting by company

#### Sorting by column

|  | 1 | Click on column header to select entire column. |
|---|---|---|

|  | 2 | Right-click anywhere in column and select Sort by **Column Name** Column. |
|---|---|---|

#### Sorting by company

|  | 1 | Click **Manage contacts from multiple companies**. |
|---|---|---|

|  | 2 | Select companies to view. |
|---|---|---|

|  | 3 | Companies are displayed (unless sorted by column) by contact type first, in the following order: |
|---|---|---|

- Client
- Job
- Vendor
