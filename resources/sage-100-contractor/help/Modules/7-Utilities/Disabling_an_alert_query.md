### Disabling an alert query

You can disable an alert query instead of deleting an alert query, if you want to have the alert query available to activate later without creating it again.

#### To disable an alert query:

|  | 1 | Open **7-6 Alerts Manager**. |
|---|---|---|

|  | 2 | Select an alert query to disable. |
|---|---|---|

|  | 3 | Click [**Disable**]. |
|---|---|---|
