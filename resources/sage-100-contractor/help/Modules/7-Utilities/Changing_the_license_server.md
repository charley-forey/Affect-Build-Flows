### Changing the license server

You can change the specified location of the license server. For example, if there is a hardware failure or you buy a new server, then you have to specify the license server the next time you launch Sage 100 Contractor.

Note: When you change the license server, the Sage 100 Contractor program closes and restarts.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To change the license server when you're already logged into a company:](javascript:void(0);)

|  | 1 | Do one of the following: |
|---|---|---|

- On the Administration Activity Center tab, and **Licensing > Change License Server**.
- From the Sage 100 Contractor menu, click **Licensing**, and then click **Change License Server**.

> Note: The Licensing menu is available only if you have hidden all Activity Centers using the Settings button.

|  | 2 | The **Change License Server** window opens. The window presents two choices. |
|---|---|---|

|  | 3 | Click one of the following links, and follow the instructions: |
|---|---|---|

- Select the computer from the list of computer on your network.
- Enter the IP Address or name of the computer.

[![Closed](http://sage100contractorhelp.sagecre.com/help/sage100contractor/US/20_5/Skins/Default/Stylesheets/Images/transparent.gif)To change the license server before logging into a company:](javascript:void(0);)

|  | 1 | Open Sage 100 Contractor. |
|---|---|---|

|  | 2 | Click [**Cancel**] in the Company List window. |
|---|---|---|

|  | 3 | Click the **Change License Server** link in the bottom right corner. |
|---|---|---|

|  | 4 | The **Change License Server** window opens. The window presents two choices. |
|---|---|---|

|  | 5 | Click one of the following links, and follow the instructions: |
|---|---|---|

- Select the computer from the list of computer on your network.
- Enter the IP Address or name of the computer.
