### About 7-5 Scheduled Reports Manager

In **7-5 Scheduled Reports Manager**, you can view and delete events recorded when scheduled reports are run.

We recommend that you view the reports manager regularly.

Important! If you do not enter a password or you enter one that is not valid when you schedule the report, the scheduled report will not run.

#### Each report displays the following information:

- ID
- Report: Displays the report number and report title.
- Schedule: Displays the current scheduled day and time.

For each scheduled report, you can:

- Edit Schedule/Output: Edit the frequency, recurrence, and schedule options for the selected report.
- Edit Selection Criteria: Edit the selection criteria for the selected report.
- Delete: Delete the selected report.

Notes:

- The reports manager displays events related to scheduled reports for all companies to which you have access.
- If you need to call Customer Support for help on a scheduled report issue, have the ID, the Report, and the Schedule information available.
