### Installing the Generic-Text Only printer driver

#### To install the Generic/Text Only printer driver:

|  | 1 | Click the **Start** button, point to **Settings**, then click **Printers**. |
|---|---|---|

|  | 2 | Double-click the **Add Printer** icon. |
|---|---|---|

|  | 3 | Follow the directions in the **Add Printer Wizard**. Be sure to do the following: |
|---|---|---|

|  | a | Under **Manufacturers**, select **Generic**. |
|---|---|---|

|  | b | Under **Printers**, select **Generic/Text Only**. |
|---|---|---|

|  | c | Then under **Available Ports**, select **File**. |
|---|---|---|
