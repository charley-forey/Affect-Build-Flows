### Deleting scheduled reports

We recommend that you regularly view the **7-5 Scheduled Reports Manager** and delete reports that you no longer need.

#### To delete a scheduled report:

|  | 1 | Open **7-5 Scheduled Reports Manager**. |
|---|---|---|

|  | 2 | Select the row for the report you want to delete. |
|---|---|---|

|  | 3 | Click **[Delete]**. |
|---|---|---|

The selected scheduled report will be deleted. More than one report can be deleted at the same time.
