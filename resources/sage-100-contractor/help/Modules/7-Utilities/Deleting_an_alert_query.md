### Deleting an alert query

You can delete an alert query.

Note: Make sure you want to permanently delete the alert. You can also disable the custom alert. [How?](Disabling_an_alert_query.md)

#### To delete an alert query:

|  | 1 | Open **7-6 Alerts Manager**. |
|---|---|---|

|  | 2 | Select the alert query to delete. |
|---|---|---|

|  | 3 | Click [**Delete**]. |
|---|---|---|
