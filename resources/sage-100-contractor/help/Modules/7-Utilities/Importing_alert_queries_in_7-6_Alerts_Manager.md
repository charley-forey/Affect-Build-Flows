### Importing alert queries in 7-6 Alerts Manager

You can import alert queries into Sage 100 Contractor.

#### To import an alert query:

1. Open **7-6 Alerts Manager**.
2. Click [**Import**].
3. Select the alert query name and click [**Import**].
4. The Alert wizard opens and steps you through importing the alert query. You can leave the settings from the alert query being imported, or customize the alert query based on your needs.
