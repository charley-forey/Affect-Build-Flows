### Setting up equipment types

Note: This functionality is available only if you have the **[Equipment Module](http://www.na.sage.com/sage-100-contractor/modules/service-management)**.

You can set up a list of equipment types, allowing you to categorize equipment. The following is an example of equipment types.

| Equip Type # | Type Name |
|---|---|
| 1 | Forklift |
| 2 | Boom truck |
| 3 | Loader |
| 4 | Platform lift |

#### To set up equipment types:

|  | 1 | Open **8-3 Equipment**. |
|---|---|---|

|  | 2 | Next to the **Equip. Type** text box, click the detail button. |
|---|---|---|

|  | 3 | In the **Equipment Type#** text box, enter the number. |
|---|---|---|

|  | 4 | In the **Type Name** text box, enter a description of the type. |
|---|---|---|

|  | 5 | Repeat steps 3–4 for each type. |
|---|---|---|

|  | 6 | On the **File** menu, click **Save**. |
|---|---|---|
