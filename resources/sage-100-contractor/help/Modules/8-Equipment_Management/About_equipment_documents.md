### About equipment documents

Note: This functionality is available only if you have the **[Equipment Module](http://www.na.sage.com/sage-100-contractor/modules/service-management)**.

**8-1-6 Equipment Documents** prints documents designed in **13-5 Form/Report Page Design** for equipment.

The types of equipment documents created can include rate cards and mileage reports. When designing an equipment document, you can merge information from the job, client, employee, and vendor files. Save the equipment documents using the *.docs_equipment file name extension.
