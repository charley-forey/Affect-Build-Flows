### Manage Period Availability

If you log on to Sage 100 Contractor as Administrator, use the Manage Period Availability window to restrict operator access to certain posting periods. The periods you lock from this window become unavailable for selection from the [Posting Period window](About_posting_periods.md).

#### To use the Manage Period Availability window:

1. Select the period to which you want to post transactions, and then click [**Select**].
2. If you have logged on to Sage 100 Contractor as Administrator and you want to restrict other operators from selecting a period, select the period you want to restrict, and then click [**Lock Access**]. Note: You cannot lock the current period. Repeat this step for each period that you want to restrict.
3. To remove restrictions from a fiscal period, select the period, and then click [**Open Access**]. Repeat this step for any other locked periods that you want to make available.
4. Click [**Save**] to save your changes.
