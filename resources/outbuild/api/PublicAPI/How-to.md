# How-to

### Introduction

Description: `These endpoint documents allow you to login to the Outbuild API and use YOUR_API_TOKEN, which will allow you to get company data with industries, industry activity data, a lookahead for an industry ID, a list of blocked industries, and verify the weekly commitments of the sector`

**Step by Step**

1. [Company](https://pp-docs.outbuild.com/docs/pp-docs#company) You must first consult the company to obtain the project list and then the **"sector_id"** ghnhb that will allow you to consult activities, tasks and other key data of the project.
2. [Sector](https://pp-docs.outbuild.com/docs/pp-docs#sector) To consult the activities of the master plan, the api of the sector must be used, the **"sector_id"** is sent and all the activities of the master plan are returned.
