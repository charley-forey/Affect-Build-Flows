# Introduction

![Section header](https://pp-docs.outbuild.com/assets/images/header-74d3f9666fc05e016c7679aed2041643.png)

### Overview

The Datahub API is designed to support your team's data analysis and visualization efforts, helping you make more informed decisions based on accessible insights. Ot provides secure, structured access to your organizations data in Outbuild, enabling integration with popular analytics tools such as Power BI, Tableau, and others.

Each data entity you work with — projects, activities, tasks, and more — can be retrieved via dedicated **endpoints**, offering flexibility in how you access and utilize your information.

*You can learn more about each endpoint in [Endpoints](https://pp-docs.outbuild.com/docs/category/endpoints) section*.

### How does it work

To use the Datahub API, you will need to make HTTP GET requests to specific URLs, known as endpoints. Each URL indicates a specific resource within the API, allowing you to access various types of information, such as projects, schedules, constraints, etc.

![image](https://pp-docs.outbuild.com/assets/images/http_diagram-9051c19280146fdccd11a77b51b43b18.png)

Each API request requires a special **token**, which serves as a key to securely access your organization’s data. It must be included as header in every request you make.

### Getting access

As a client, you can gain access to our API by **reaching out to one of our Customer Success representatives** and providing your first name, last name, email address, and organization name. They will guide you through the process and provide the necessary authorization details you will need to integrate our API with any application of your choice.
